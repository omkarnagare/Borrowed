FAQs

Frequently Asked Questions

I am a Giver. I have so many items listed in the "Home" tab. It's very hard for me to find one of them.

The team borrowed appreciates people with a big heart. User can use "Search" icon present at the top to browse through the items.

I want to remind the other person about the item.

Users can go to "Item Details" by clicking on Item from the list. There are numerous social sharing options provided to remind them.

The other person is not on any of the social networking options provided.

You worry too much. There is a generic share option provided with "Share" icon. You can use this to connect to other person in every possible way supported by your phone.

I want to edit the information provided earlier for my item.

Unfortunately, there is no direct way to edit the item. The user has to delete the current item for which he/she wants to change the details and create a new item in the list with the new details.

I want to know about Urgent Items.

Items which need to be urgently get back from or to be returned to the other person are said to be urgent Items. These items can be viewed in "Urgent Items" tab

I want to mark my item as Urgent.

Users can use (Empty)"Heart" icon present at the top in the item details. Alternatively, User can click on (Empty)"Heart" icon which will be shown after Left-sliding the Item-view on the "Home" tab. Filled "Heart" icon will indicate that your Item is an Urgent item.

I accidently marked my item as Urgent.

Don't worry. Users can click on (Filled)"Heart" icon present at the top in the item details. Or, User can use (Filled)"Heart" icon which will be shown after Left-sliding the Item-view on the "Home" tab. Empty "Heart" icon will indicate that your Item is not an Urgent item.

I want to remove the item from the list now that I have got back/returned the item.

This is also known as "transaction-complete" item. Users can use "Tick" icon which will be shown after Right-sliding the Item-view on the "Home" tab or "Urgent Items" tab. This will remove the item from "Home" tab (and "Urgent Items" tab if the item was urgent).

I want to view the items for which the borrowing transaction (got back/returned) is completed.

The user can go to "Account" tab. and Click on "Transaction Complete Items". The items will be listed in the "Done Items" page.

I want to remove the item completely meaning I don't want an Item to show in "Done Items" page.

User can use "Tick" icon which will be shown after Right-sliding the Item-view on the "Done Items" page. Please note that, the item once removed completely, can not be made available again.

You have a bad taste Team Borrowed. I don't like the default color scheme.

User can change the theme for the "Borrowed" app by going to "Theme" section of "Settings" tab.

I am facing an issue which is not listed here.

Please use "Contact us" section in "Settings" tab to write to us. Please be detailed and specific in your query. The team borrowed will get in touch with you regarding the issue once we receive the issue.

The "Borrowed" app is awesome. I want to know/meet/greet the developer to show the gratitude.

Please don't forget to rate "Borrowed" app which you like so much. You can go to the "About developer" section of "Settings" tab to know about the Developer. And You can greet Or meet the developer on the social platforms, links for which are provided.
